Tech Stack
----------
Frontend:
  ⚛️  Next.js 15 (App Router)
  📘 TypeScript (strict mode)
  🎨 Tailwind CSS (black/white/zinc)
  🧩 Shadcn UI (Radix primitives)
  🔍 Lucide Icons
  🔄 TanStack Query v5
  ✅ Zod validation
  🌐 next-intl

Backend:
  🗄️  Supabase (PostgreSQL)
  🔐 Supabase Auth (JWT)
  🛡️  Row Level Security (RLS)
  ⚡ Real-time (ready)
